# 私人阅览页方向契约

模式：Operate，兼顾Read。目标是一次触摸回到真实书籍，第二个入口回到真实旧思想。

THESIS：让书籍和人的旧表达占据首页，不用统计卡片阵列定义阅读。

OWN-WORLD：黑白灰；中文正文与宋体类引文；深色实心阅读按钮；直线分栏与书目索引；无动画、阴影和装饰纹理。

STORY：先看到继续书，再重访一句话，随后进入分类或记录。每项推断能查看证据并撤回。

FIRST VIEWPORT：758×1024竖屏预览。页眉后为真实封面与书名，阅读按钮紧邻；中段一条真实想法；下段两条主题索引；底部固定四个必要入口。长内容在正文区滚动，导航保留。

FORM：选择方案A“私人阅览页”。用户指定独立提出三个方向并选最适合的实现；不额外要求用户选择。concept-seed运行因缺少引擎失败，没有seed key；使用用户固定的视觉语法。HTML代码实现，不用生成图片替代交互。

FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

验收：真实数据、书籍详情/笔记/统计/纠正交互，桌面及设备尺寸截图检查；不声称HTML已经拥有原生系统功能。
