# 摘抄页 · 0.3 浏览器预览

用户反馈0.2.2不够简约、没有设计感，确认第一眼突出摘抄正文，时间和应用安静陪衬；已同意先制作设备比例静态预览，再决定设备更新。当前仅改浏览器原型，设备保留0.2.2。模式为Read，兼顾Launcher基本操作。

## Direction contract

THESIS：一页真实摘抄成为桌面主体，以明确文字层级与单栏对齐获得安静的辨识度。

OWN-WORLD：白底、黑灰字、一种清晰中文字体、细线功能图标；留白承担分区，不增加装饰物。

STORY：先读正文，再看到书名；轻触查看完整出处或换一则，底部随手进入阅读App。

FIRST VIEWPORT：顶部一行小时间、日期、真实电量或预览标识及齿轮；正文从上半部固定基线展开，书名和小字“换一则”沿同一左边线跟随；底部三应用入口固定。无大引号、页角、印记、题签或首页分隔线。长短正文使用相同字号；作者、划线日期、章节在出处页。

FORM：用户明确选择“正文先行”规划，沿用既定纯白单色体系作精确的层级收敛，无新方向抽签或新图像。先检查设备比例与窄屏/桌面浏览器；不构建APK或写入设备。

FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

数据：沿用已授权的本机463条真实划线，不改写正文或补造来源。无数据保留空状态与失败重试。0.2.2源码存档archive/v0.2.2供对照；原壁纸资产不变。

用户追加：留少量隐藏彩蛋，界面不要防御性说明。长按书名650ms随机回访同书另一条，长按“换一则”回到上一条；Shift+Enter提供键盘等价动作。彩蛋不增加页面标签、装饰或自动切换。作者/日期/章节仍在出处页；来源保留为“微信读书·我的划线”，移除立场解释、真伪自述与摘抄池统计等附加段落。未知电量留空。

后续用户已确认更新机器，授权将本预览构建为0.3.0/code6并安装；先前“仅预览”记录为当时阶段边界。构建与签名验证已通过，设备安装结果见reports/12-minimal-deployment.md。
