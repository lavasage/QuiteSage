# 标本与秩序：桌面与锁屏

用户已确认版画提案，并明确要求桌面直接放App入口和时间日期挂件。该决定替代v1阅读首页；不把书架、阅读统计或笔记列表继续搬到桌面。用户偏好静态展示、轻触探索，不增加输入任务。

## Direction contract

THESIS：桌面中央是一页从私人阅读档案随机拾取的真实划线，以中文排版与留白表达个性，桌面承担真实的App启动与时钟日期。用户最新要求替代了中央版画，锁屏原画保留。

OWN-WORLD：纯白纸面、黑白种荚木刻式版画、少量深灰文字与细分隔线。原画标题“种子与尺度”，主题词“概念·生命·语言”为艺术归纳，不是本人引文或科学统计。

STORY：锁屏看到完整作品，解锁后重访一条旧划线；顶部直接读时间日期，底部一触打开微信读书、多看与应用抽屉，角落保留设置和旧桌面回退。轻触“换一则”随机换条，书名进入出处；不自动轮播。

FIRST VIEWPORT：竖屏顶部大时间与右侧完整日期/星期/电量，中部为宋体划线正文、右侧书名与作者，下方“换一则”，底部“旧页新读”题签、齿轮与三个宽触摸入口。目标设备一屏显示；较矮屏中央区域可滚动，系统入口始终保留。

0.2.2细节：用户确认已在实机看到摘抄，并希望“再加点小设计”。正文两侧加入细线页角，出处左侧显示真实划线日期，底部题签配竖排“拾句”小印记。保留原文、字号、功能层级和锁屏；缺少时间时隐藏日期，不补造年代。换条图标与文字采用单一9px间距，兼容WebView61。

FORM：用户选择“标本与秩序”，确认生成的双屏提案，并将桌面动作改成App入口。背景原画使用imagegen制作，时钟和按钮使用真实HTML；不将生成的UI字样当成交互实现。无随机seed；前期引擎缺失已记录。

FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

设备：EPD106、Android8.1/WebView61、758×1024物理像素、212逻辑DPI。Android端时间按系统广播更新；浏览器仅分钟更新。摘抄来自本机快照，筛选完整划线28–110字符、书名作者可用并去重，不按观点筛选。正文不改写。当前463条、69本书。首次打开随机，用户主动切换；Home返回保持当前条目，避免无意刷新。同一洗牌周期不重复，跨周期不立即重复。离线APK仅打包筛选后的文字与出处；密钥和完整阅读快照不打包。
